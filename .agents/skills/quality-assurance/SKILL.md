# Quality Assurance & Testing Skill

Use this skill to design, run, and evaluate tests across the project.

## Verification Checklist

1. **Unit & Integration Testing**: Execute automated test suites and verify exit status.
2. **Edge Case Coverage**: Test null values, empty collections, unexpected types, and extreme ranges.
3. **Log & Trace Inspection**: Review runtime logs for hidden warnings or uncaught exceptions.
