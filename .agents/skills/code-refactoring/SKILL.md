# Code Refactoring Skill

Use this skill when refactoring scripts, modules, or services in this repository.

## Guidelines

1. **Safety First**: Verify test coverage or create baseline tests before modifying code logic.
2. **Incremental Edits**: Make targeted, modular edits rather than sweeping re-writes.
3. **API Integrity**: Preserve existing function signatures and public APIs unless explicitly requested.
4. **Performance & Cleanliness**: Remove dead code, eliminate redundancy, and apply optimal algorithms.
