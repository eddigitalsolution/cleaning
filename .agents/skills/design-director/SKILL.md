# Master Design Director Skill

This skill enforces high-end art direction, visual polish, micro-interactions, responsive architecture, and deployment standards for web projects.

---

## 🎨 Art Direction & Visual Aesthetics

1. **Unique Visual Identity**:
   - Establish curated color palettes using custom CSS variables / HSL tokens (e.g. deep slate background, warm accent accents).
   - Avoid generic browser default styling or unstyled components.

2. **Typography**:
   - Combine expressive display fonts for headers (e.g. Outfit, Plus Jakarta Sans) with readable body fonts (e.g. Inter).

3. **Micro-Interactions**:
   - Add responsive hover states, smooth transitions, and dynamic visual feedback on interactive elements.

---

## 🚀 Quality & Performance

1. **Accessibility & Usability**: Full keyboard navigation, semantic HTML elements, labeled inputs.
2. **Performance Target**: Optimize visual assets, lazy load heavy UI components, achieve 90+ Lighthouse rating.
